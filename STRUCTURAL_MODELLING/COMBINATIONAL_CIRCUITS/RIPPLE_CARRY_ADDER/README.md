 Ripple Carry Adder – Structural Modeling

**Author:** Halima Diyauddeen

---

 Overview

This project implements a **4-Bit Ripple Carry Adder (RCA)** using **Structural Modeling** in Verilog. A Ripple Carry Adder adds two 4-bit binary numbers along with an input carry (`cin`) and produces a 4-bit Sum output and a final Carry output. The circuit is constructed by cascading four Full Adder modules.

---

 Objective

- Understand how larger arithmetic circuits are built from smaller modules.
- Learn module instantiation in Structural Modeling.
- Implement a 4-bit Ripple Carry Adder using Full Adders.
- Verify the design using randomly generated test vectors.

---

 Structural Implementation

The design consists of four Full Adder modules connected in cascade. The carry output of each Full Adder becomes the carry input of the next Full Adder.

```verilog
full_adder fa0 (...);
full_adder fa1 (...);
full_adder fa2 (...);
full_adder fa3 (...);
```

The carry generated by each stage "ripples" to the next stage until the final carry output is produced.

 Verilog Implementation

The design uses:

- Module instantiation
- Internal wires
- Structural Modeling

The implementation relies on the previously designed `full_adder` module. No `always` blocks, `assign` statements, or behavioral operators are used.

---

 Simulation

The testbench generates random input values using Verilog's `$random` system function and applies them using concatenation.

```verilog
repeat (10) begin
    {a, b, cin} = $random;
    #10;
end
```

> **Note:** Concatenation (`{}`) is used because the Ripple Carry Adder has three separate input signals (`a`, `b`, and `cin`). This allows all inputs to receive random values simultaneously, making the testbench concise, readable, and scalable.

---

 Conclusion

The **Ripple Carry Adder** demonstrates how larger arithmetic circuits can be constructed by cascading smaller building blocks. By connecting four Full Adders, the design performs 4-bit binary addition while propagating the carry from one stage to the next. This modular approach is widely used in digital system design and serves as the foundation for more advanced adder architectures.
